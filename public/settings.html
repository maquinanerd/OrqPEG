Configuração global

Somente leitura. O painel não grava configuração: a edição é feita direto no arquivo.

Onde editar

A configuração global fica no arquivo config/global.json, dentro da pasta de instalação do OrqPEG. Edite esse arquivo com um editor de texto e reinicie o painel para aplicar as mudanças.

  • panel.host e panel.port — endereço do painel; o host é sempre restrito a 127.0.0.1.
  • agents.claudeCommand e agents.codexCommand — executáveis locais chamados pelo orquestrador.
  • agents.claudeTimeoutSeconds e agents.codexTimeoutSeconds — tempos-limite de cada agente.
  • security.blockWhenApiKeysPresent, security.strippedEnvVars e security.warnEnvVars — política de segurança de variáveis de API.
  • git.allowForcePush — permanentemente falso: force push é proibido pelo produto.

A API do painel expõe apenas GET /api/home e GET /api/diagnostics para leitura de ambiente. Tempos-limite e modelos padrão não são publicados pela API e por isso não aparecem abaixo: consulte-os direto no arquivo.
